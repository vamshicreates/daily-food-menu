# Daily Food Menu

Static website listing 30 interesting, easy veg dishes (curries, pulusu, dals, gravies) from the Amma Chethi Vanta YouTube channel. Veg/non-veg toggle (non-veg coming next), search and category filters, and a "Today's pick" that changes daily.

No build step. Open `index.html`, or deploy the folder as a static site. Dishes live in `data.js`.

Recipes and videos belong to their creator; this site only links to them.
