# Daily Food Menu

Static website listing 60 interesting, easy dishes (30 veg and 30 non-veg: curries, pulusu, dals, gravies, fries) from the Amma Chethi Vanta YouTube channel. Veg/non-veg toggle, search and category filters, and a "Today's pick" that changes daily.

No build step. Open `index.html`, or deploy the folder as a static site. Dishes live in `data.js`.

Recipes and videos belong to their creator; this site only links to them.
